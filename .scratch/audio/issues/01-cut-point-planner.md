# 01: 切點規劃純函式

**What to build:** 一個純函式，給定錄音總長度、靜音區間、目標 chunk 長度和硬上限，回傳每個 chunk 的起訖時間。切在離目標長度最近的靜音內；視窗內沒有靜音時，在目標長度硬切。不碰 ffmpeg、不做 I/O。這是 spec 的第二個測試切入點。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 每個 chunk 都不超過上限
- [x] chunk 首尾相接，沒有重疊、沒有縫隙，涵蓋整段錄音
- [x] 切點嚴格遞增，不產生長度為 0 的 chunk
- [x] 允許視窗內有靜音時，切點落在該靜音區間內；沒有時才在目標長度硬切
- [x] 邊界案例有參數化測試：完全沒有靜音、靜音在開頭或結尾、靜音比 chunk 還長、總長度等於／略小於／略大於上限、大量密集靜音
- [x] 一兩個具體例子固定「選最近的靜音」這條規則
- [x] 測試不需要 ffmpeg，在沒有 ffmpeg 的環境也能跑
